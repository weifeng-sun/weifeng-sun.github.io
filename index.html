I am currently a research scientist at Singapore Management University, advised by Prof. David Lo.

Prior to that, I received my Ph.D. degree from Chongqing University, China, under the supervision of Dr. Meng Yan.

Research Interests

I have published over 35 papers citations 598 at top international conferences and journals in software engineering, artificial intelligence, and security, including ICSE, ASE, ISSTA, ACL, AAAI, TSE, TOSEM, and EMSE. My research lies at the intersection of artificial intelligence, software engineering, and software security. I am particularly interested in:

  • Security and Trustworthiness of Code LLMs: secure code generation and model editing (ISSTA’26, TSE’26), adversarial and jailbreak attacks on code models (ICSE’25, TSE’26, ACL’26), security risks of LLM long-term memory (ISSTA’26), social bias in LLM-generated code (ASE’26), and vulnerability detection (Internetware’24).
  • LLMs and Agents for Software Engineering: code generation (AAAI’26), generation-quality enhancement and knowledge distillation for code models (TOSEM’26, EMSE’26), LLM-based and multi-agent program repair (ASE’26), and reliability of agent systems (ASE’26).
  • Software Testing and Assertion Generation: assertion generation (ASE’23, TOSEM’24, TSE’25, ISSTA’26), testing of deep learning systems (TSE’23, TOSEM’24, TSE’25), and adaptive random testing and test prioritization (TSE’19, TR’19, TSE’24).
  • Software Evolution and Maintenance: test-to-code traceability and co-evolution (TOSEM’23, TSE’24), bug report understanding (JSS’23, ASEJ’25), method name updating (QRS’23), and security-fix backporting for CI/CD workflows (ICSE’27).
